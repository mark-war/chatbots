# AI Finance Chatbot — Free & Embeddable

**Live Demo**: https://finance-chat.vercel.app  
**Embed Widget**: `<finance-chat>`

## Features

- Upload CSV → AI auto-categorizes
- Ask in English: "How much did I spend on dining?"
- Real MongoDB answers
- 100% FREE (Groq + MongoDB Atlas)

## Tech Stack

- **Frontend**: Next.js + Tailwind
- **Backend**: Express + MongoDB
- **AI**: Groq (free tier)
- **Deploy**: Vercel + Render

## Embed in 1 Line

```html
<script src="https://finance-chat.vercel.app/widget.js"></script>
<finance-chat data-user-id="your-client-id"></finance-chat>
```
